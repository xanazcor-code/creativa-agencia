## 🎯 Objetivo
Desarrollar y publicar un sitio web empresarial para una agencia de publicidad, utilizando **únicamente HTML5 y CSS3**, desplegado en **Microsoft Azure App Service** conectado con GitHub.

## 🛠️ Tecnologías
- ✅ HTML5 (etiquetas semánticas)
- ✅ CSS3 (Flexbox, Grid, Media Queries, :hover)
- ✅ Diseño totalmente responsive
- ❌ Sin JavaScript, sin Bootstrap, sin frameworks
- ☁️ Azure App Service — Web App
- 📦 GitHub como repositorio

## 📁 Páginas del Sitio
- Inicio — index.html
- Nosotros — nosotros.html
- Servicios — servicios.html
- Contacto — contacto.html
